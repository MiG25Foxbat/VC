# Агент откликов

Инструмент для личного поиска работы. Находит вакансию, собирает данные о компании и её руководителе из открытых источников, пишет сопроводительное письмо под конкретную вакансию.

Полная спецификация в @docs/BUILD.md. Здесь только то, что должно действовать в каждой сессии.

## Жёсткие ограничения

Бэкенд живёт на бесплатном тарифе Render. Из этого следует:

- 512 МБ памяти. Playwright, Selenium и любой headless-браузер не влезают. Не предлагать и не ставить.
- Сервис засыпает через 15 минут простоя. Планировщик внутри процесса не работает. APScheduler не использовать.
- Диск временный, файлы стираются при засыпании. Postgres и SQLite на сервере не использовать.
- Бэкенд без состояния. Всё, что найдено и ещё не отправлено, хранит клиент на устройстве.
- Кеш только в памяти процесса, с TTL. Максимум 7 суток на запись.

## Правила, которые нарушать нельзя

1. **Модель не придумывает факты.** Всё, что модель пишет о компании или человеке, берётся только из переданного ей контекста. Каждое утверждение в письме попадает в массив `facts` со ссылкой на источник. Если данных мало, письмо пишется короче, а не дополняется догадками.
2. **Персональные данные не хранятся.** Ни в базе, ни в логах, ни в файлах. Карточка живёт в кеше до отправки, отказа или истечения TTL. В лог пишется только идентификатор вакансии и статус.
3. **avito.ru как источник не подключается.** Решение продуктовое, не техническое. hh.ru
   раньше был в этом же списке — запрет сняли 2026-09-24 по прямому запросу продукта,
   осознанно, зная, что это не официальный API, а чтение HTML в обход `robots.txt`
   (см. `server/sources/hh.py`). Это точечное исключение для hh.ru, а не отмена общего
   принципа «не обходить защиту от автоматического доступа» — он по-прежнему действует
   для любого нового источника, кроме уже одобренного hh.ru.
4. **Провайдер LLM берётся из переменных окружения.** Ни одного вызова модели с захардкоженным адресом или именем модели.
5. **Никаких секретов в репозитории.** Только `.env.example` с пустыми значениями.

## Структура

```
server/          Python 3.12, FastAPI. Вся логика.
  sources/       Адаптеры источников вакансий
  sources/config/*.yaml   Селекторы для уровня L2, в данных, не в коде
  enrich/        Реестры, сайт компании, отзывы
  llm/           Клиент модели и промпты
  api/           Эндпоинты
tests/
  fixtures/      Сохранённые ответы и HTML. Тесты парсеров работают без сети.
app/             Flutter-клиент
docs/BUILD.md    Спецификация: контракт, промпты, критерии готовности
```

## Команды

```bash
cd server && uv run uvicorn api.main:app --reload   # запуск API локально
cd server && uv run pytest                          # тесты
cd app && flutter run                               # клиент
```

## Конвенции

- Python 3.12, типы обязательны на всех публичных функциях, pydantic для всего, что пересекает границу процесса.
- Комментарии и docstring по-русски, имена переменных и функций по-английски.
- Асинхронно всё, что ходит в сеть. httpx, не requests.
- selectolax для разбора HTML, не BeautifulSoup.
- Каждый источник закрывается тестом на фикстуре. Новый источник без фикстуры не принимается.
- Flutter: Riverpod для состояния, freezed для моделей. setState только в самых простых виджетах.

## Порядок работы

Сборка идёт шагами, они описаны в docs/BUILD.md с критериями готовности. Не начинать следующий шаг, пока предыдущий не проходит свои критерии. Не писать UI, пока API не отдаёт настоящие данные.
